半格电｜另一条人生 V1.3

这版专门修复手机直接打开本地 HTML 时的两个问题：
1. 人物图显示失败；
2. 点击“生成居民档案卡”报未知错误。

原因：手机浏览器在 file:// 本地页面下对 Canvas + 本地图片限制不一致。
V1.3 不再用 Canvas 生成试玩档案卡，而改为浏览器原生 HTML 档案卡，因此本地手机兼容性更高。

试玩：
- 解压后保持 index.html 和 assets 文件夹在一起；
- 双击/浏览器打开 index.html；
- 生成人生后点击“生成居民档案卡”；
- 会弹出完整档案卡，试玩阶段可直接手机截图。

正式上线后，再实现一键导出高清 PNG。
